## Generation prompt (canonical)

Use this prompt (or a faithful derivative) when regenerating the mark:

```text
Premium 3D product logo mark for "Rashid Agent" — a local-first AI coding assistant
and multi-tenant knowledge platform. Square app-icon composition, centered hero emblem only.

SUBJECT: A sculpted 3D monogram formed by a bold capital letter R fused with a subtle
code-bracket motif (abstract angular { } silhouette integrated into the R’s vertical spine).
The mark feels like precision-machined metal + polished glass, not a cartoon mascot.
Tiny soft emissive edge-lights suggest streaming intelligence, without looking like a robot face.

MATERIAL & LIGHTING: Studio product render. Brushed deep graphite / gunmetal body,
razor-clean bevels, soft specular highlights, faint cyan (#2DD4BF to #22D3EE) inner glow
along the inner edge of the R. Subtle warm silver rim light. Physically based materials,
high micro-detail. Octane/Cinema4D quality.

COMPOSITION: Centered emblem occupying ~70% of frame. Generous margin. Perfectly balanced
for GitHub README header and favicon crop.

BACKGROUND: Seamless near-black (#0B1220) with extremely soft vignette — no floor,
no props, no scene clutter.

TEXT: No readable words, no Persian calligraphy, no scales of justice, no laurel wreath,
no shield crest, no law/court symbols, no crown, no emoji, no bird silhouette.

STYLE CONSTRAINTS: Professional SaaS / developer-tools branding. Avoid purple gradients,
neon cyberpunk overload, cheap chrome, plastic toy look, sticker outlines, flat 2D clipart.

OUTPUT FEEL: Elite, trustworthy, modern tech product identity — calm confidence,
engineering craft, AI precision.
```
